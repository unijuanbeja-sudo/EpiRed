# EpiRed

Repositorio general del proyecto EpiRed desarrollado para la asignatura de Estructuras de Datos No Lineales.

## Parcial del corte 2

La solución actualiza el archivo del Taller 2, sin cambiar las otras versiones.
Consulta [la guía y las instrucciones](EpiRed_Taller2/README.md).

```powershell
cd EpiRed_Taller2
python main.py
python main.py --demo
python -m unittest discover -s tests -v
```

Los guiones individuales de Juan, Sofía y Vanessa están en
`EpiRed_Taller2/exposiciones/`, en Word editable y Markdown.

El proyecto está orientado al sector de salud y epidemiología y utiliza diferentes estructuras de datos para representar y procesar información epidemiológica.

## Versiones del proyecto

### Versión 1 - Árbol N-ario

Primera versión funcional de EpiRed.

Se utiliza un árbol n-ario para representar:

- Departamentos.
- Municipios.
- Centros de salud.
- Enfermedades.

Incluye funcionalidades para:

- Mostrar la estructura.
- Buscar enfermedades.
- Agregar enfermedades.
- Eliminar enfermedades.

La documentación completa de esta versión se encuentra dentro de:

`version-1-arbol-nario/README.md`
